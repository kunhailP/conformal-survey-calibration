\section*{Data availability}

No microdata are redistributed with this work. The European Social Survey
integrated files for rounds 9--11 are obtained from the ESS data portal under its
End User Licence; \texttt{experiments/fetch\_ess.py} retrieves them through the
portal's API, so the analysis reproduces from source for any licence holder. No
user identifier is stored in the replication repository and the local cache is
written outside it. All simulation results reproduce from the repository alone.

\section*{Replication}

Every number in this paper traces to a row of \texttt{docs/CLAIMS.md} in the
replication repository, which also records the protocol written before each
experiment was run and the claims that were subsequently retracted.
