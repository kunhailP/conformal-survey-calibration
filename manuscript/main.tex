\section*{Data availability}

No microdata are redistributed with this work. The European Social Survey
integrated data files for rounds 9, 10 and 11 are obtained from the ESS data
portal under its End User Licence; the replication materials include a script
that retrieves them through the portal's application programming interface, so
the analysis reproduces from source for any licence holder. No user identifier is
stored in the replication materials and the local cache is written outside them.
All simulation results reproduce from the replication materials alone. Those
materials are supplied with this submission for the reviewers.

\section*{Replication}

Every numerical statement in this paper corresponds to an entry in a claims file
in the replication materials, which also contains the protocol written before
each experiment was executed, including its predictions, and records the claims
that were subsequently retracted.
